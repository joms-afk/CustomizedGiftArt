CGA CONTACT WEBSITE

Files:
- index.html: website structure and contact links
- style.css: responsive design for phones, tablets, and computers
- script.js: small click feedback effect

Before publishing:
1. Open index.html.
2. Find YOUR_FACEBOOK_PAGE_URL and replace it with your real Facebook Page URL.
   Example: https://www.facebook.com/YourPageName
3. Find YOUR_EMAIL@example.com and replace it with your real email address.
4. Keep all three files in the same folder.
5. Open index.html in a browser to preview, then upload the files to your web host/GitHub Pages.

The phone button is already set to call 09556846120. On a phone, tapping it opens the phone dialer.
